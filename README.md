# PNU Halloween demo

시연용 이벤트 페이지입니다. 행사 정보와 결제 흐름은 예시입니다. 실제 결제는 처리하지 않습니다.

Supabase `public.halloween_events`에 세션별 방문, 티켓 노출, 신청 시작, 체험 완료, 버튼 클릭과 UTM을 기록합니다. 브라우저 세션 기준이므로 새 탭은 별도 세션입니다. 광고 차단기나 네트워크 오류로 누락될 수 있으며, 브라우저에서 보내는 데이터는 검증된 매출 데이터가 아닙니다. 개인정보는 입력받지 않습니다. 공개 키는 삽입에만 사용되고 데이터 읽기는 차단됩니다.

Supabase SQL Editor에서 `analytics.sql`을 실행해 세션 단위 퍼널과 버튼 클릭을 확인하세요. 전환율은 체험 완료 수 / 방문 세션 수입니다. 실제 구매 전환율을 측정하려면 결제 서비스의 서버 검증 완료 이벤트가 필요합니다.

공개 대시보드 `dashboard.html`은 `halloween_dashboard()` 함수가 반환하는 전체 기간 집계 및 최근 30일 일별 집계를 표시합니다. 원본 행은 읽을 수 없지만, 대시보드 집계 수치는 누구나 볼 수 있습니다. 퍼널은 같은 세션에서 각 단계의 존재 여부로 계산하며 단계의 시간 순서는 검증하지 않습니다. 일별 완료는 해당 날짜의 완료 이벤트 기준이며 전체 퍼널의 완료 수와 집계 기준이 다릅니다.
